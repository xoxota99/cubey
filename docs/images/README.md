# Documentation Images

This directory contains images used in the Cubey documentation.

## Image Files

- `components_diagram.png`: Overview of all hardware components
- `frame_assembly.png`: Diagram showing how to assemble the frame
- `motor_installation.png`: Instructions for installing motors
- `wiring_diagram.png`: Detailed wiring schematic
- `camera_mounting.png`: Camera positioning guide
- `lighting_setup.png`: Optional lighting configuration
- `web_interface.png`: Screenshot of the web interface
- `calibration_process.png`: Visual guide to the calibration process

## Adding New Images

When adding new images to the documentation:

1. Use clear, high-resolution images
2. Optimize file sizes for web viewing
3. Use descriptive filenames
4. Update this README with the new image information
